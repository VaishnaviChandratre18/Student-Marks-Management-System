***Student Marks Management System • Python***



**Project Overview**



This project is a Python-based Student Marks Management System designed to manage student academic records efficiently. It provides features for adding and displaying student marks, calculating average performance, identifying the highest-scoring student, and interacting with the system through a user-friendly menu-driven interface.



**Tools used**



Jupyter Notebook



**Features**



\-Add student names and marks

\-Display all stored student records

\-Calculate the average marks of all students

\-Identify the top-performing student

\-Handle cases where no student records are available

\-Continuous menu-driven interaction until the user chooses to exit



**Workflow**



1\. Display a menu with available operations.

2\. Accept the user’s choice.

3\. Store student names and marks in a \*\*dictionary\*\*.

4\. Calculate averages using Python’s built-in functions.

5\. Find the highest-scoring student using `max()` with `key=students.get`.

6\. Exit the program when the user selects \*\*Goodbye\*\*.



**Result**



The program successfully demonstrates student record management, average calculation, top-student identification, and menu-driven interaction using Python.
